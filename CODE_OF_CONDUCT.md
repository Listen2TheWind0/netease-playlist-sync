# Code of Conduct

## Our Standard

Contributors are expected to be respectful, constructive, and precise. Help
others reproduce problems, explain trade-offs, and disagree with ideas rather
than people.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
deliberate exposure of credentials or private data, spam, and abusive
automation against third-party services or repositories.

## Scope

This Code of Conduct applies to Issues, Pull Requests, discussions, commits,
and other project spaces maintained for this Skill.

## Enforcement

Report conduct concerns privately through the repository's GitHub contact or
private reporting features. Do not publish private evidence, credentials, or
personal information in a public Issue.

Maintainers may edit, reject, or remove contributions that violate this
standard. Retaliation against good-faith reports is not acceptable.

## Attribution

This document is a concise project-specific policy inspired by common open
source community standards.
